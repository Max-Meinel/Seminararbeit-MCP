# LLM-Prompts zur Literaturbeschaffung

Kopiere diese Prompts einzeln in ein anderes LLM (ChatGPT, Claude, Perplexity), um relevante Quellen zu finden.

## Prompt A: SAP CAP & Cloud-Native Frameworks

```
Ich schreibe eine Bachelorarbeit über SAP Cloud Application Programming Model (CAP) und benötige wissenschaftliche Literatur zu folgenden Themen:

**Themengebiete:**
- Cloud-native application development patterns
- Enterprise application frameworks
- Multi-tenancy architecture
- Service-oriented architecture in cloud environments
- Cloud computing patterns and best practices

**Anforderungen:**
- Bevorzugt: Bücher von anerkannten Verlagen (Springer, O'Reilly, Morgan Kaufmann, Addison-Wesley)
- Publikationsjahr: 2010-2025
- Sprache: Englisch oder Deutsch
- Zugang über Hochschulbibliotheken möglich

**Ausgabe pro Quelle:**
- Vollständige Zitation (Autor, Jahr, Titel, Verlag)
- ISBN/DOI
- Kurze Beschreibung der Relevanz (1-2 Sätze)
- Link zur offiziellen Quelle (Verlag, SpringerLink, etc.)
- Verfügbarkeit über deutsche Hochschulbibliotheken
```

```

**Anforderungen:**
- Fokus auf Grundlagenwerke und Standardliteratur
- Publikationsjahr: 2000-2020
- Verlag: Addison-Wesley, O'Reilly bevorzugt
- Verfügbar über Safari Books oder O'Reilly Learning

**Ausgabe pro Quelle:**
- Vollständige Zitation
- ISBN
- Relevanz (welche DDD-Konzepte werden behandelt?)
- Zugangslink (Verlag, Safari Books, O'Reilly)
```

## Prompt D: Compiler-Theorie & DSL-Parsing

```
**Anforderungen:**
- Mix aus Theorie (Standardwerke) und Praxis (Pattern-Bücher)
- Publikationsjahr: 2000-2025
- Verlag: Pearson, Addison-Wesley, Pragmatic Bookshelf, O'Reilly
- Verfügbar über O'Reilly Learning oder als eBook

**Ausgabe pro Quelle:**
- Vollständige Zitation
- ISBN
- Relevanz (Theorie vs. Praxis, welche Aspekte werden behandelt?)
- Link zum Verlag oder eBook-Plattform
```
